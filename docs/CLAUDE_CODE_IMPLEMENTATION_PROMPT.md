# Claude Code 実装指示

以下の要件でAyonix Zoomerを本番実装してください。既存モックアップのデザイン、配色、情報設計、レスポンシブ挙動を維持し、機能を段階的に実装します。

## 実装順序

1. 認証、組織、ユーザー、RBAC
2. 受講者CRUD、CSV取込、顔登録、品質判定
3. 研修CRUD、受講者割当、Zoom OAuth連携
4. 受講者用プレチェック画面、同意、カメラ取得、1:1照合
5. 継続監視SDK、離席・複数人・閉眼の連続判定
6. リアルタイム管理画面、アラート、レビュー
7. 証跡画像、保持期間、自動削除、監査ログ
8. レポート、通知、運用監視、負荷試験

## 必須ルール

- 通常のZoomクライアントから参加者映像を外部取得する前提にしない
- 受講者用Zoomer画面でカメラ同意を取り、可能な処理は端末内で行う
- 顔特徴量、原画像、署名URL、アクセストークンをログへ出力しない
- 全DBアクセスで `organization_id` を必須にし、テナント越境テストを追加
- 変更APIは入力検証、権限検証、監査記録、冪等性を実装
- 自動判定だけで不合格にせず、管理者レビュー状態を持つ
- エラー、空状態、読み込み、再接続、権限拒否をUIへ実装
- すべての機能に成功・失敗・境界値テストを追加
- README、`.env.example`、マイグレーション、シード、デプロイ手順を更新
